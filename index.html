My point of view

The model is only one part of the product.

AI creates value when the surrounding system can convert a signal into a safe, explainable action. That means grounded data, bounded tools, observable workflows, deterministic fallbacks, and an operating loop that can act on what the model discovers.

My work explores that boundary: the model can plan, infer, and assist; the application still owns truth, policy, validation, and outcomes.

OpenOMS

An inspectable order-sourcing kernel where CP-SAT owns multi-line fulfillment decisions and AI agents interact through bounded MCP tools outside the inventory commit path.

  • Joint optimization enforces line assignment and aggregate inventory constraints
  • Policy weights make distance-versus-consolidation tradeoffs explicit
  • Bounded MCP tools expose sourcing, constraint relaxation, alternatives, and explanations
  • Repeated sourcing evaluation reports latency, feasibility, shipments, and distance
