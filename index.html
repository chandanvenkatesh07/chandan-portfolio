My point of view

The model is only one part of the product.

AI creates value when the surrounding system can convert a signal into a safe, explainable action. That means grounded data, bounded tools, observable workflows, deterministic fallbacks, and an operating loop that can act on what the model discovers.

My work explores that boundary: the model can plan, infer, and assist; the application still owns truth, policy, validation, and outcomes.

Retail Associate Assistant

A local-first voice assistant that listens in shadow mode, resolves common store questions on a deterministic fast path, and uses a grounded model only when the request is ambiguous.

  • Sub-second fuzzy lookup keeps the LLM off the common path
  • Conversation shadowing preserves customer and associate context
  • Confidence gating controls grounded model escalation
  • Private spoken cues support the associate without interrupting the interaction
