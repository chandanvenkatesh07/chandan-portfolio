Retrieval · Grounded voice AI

Retail Associate Assistant — Retrieval and Grounded AI for Commerce

Chandan VenkateshNovember 10, 2026Private source · Synthetic evaluation

The assistant is designed for a stricter problem than general chat: decide whether a private earpiece cue would help, retrieve authoritative store facts, and stay silent when the system cannot ground a safe answer.

Evidence boundary: source was independently inspected at commit 6c794eaf. Results use 34 synthetic fixtures and a deterministic 907-product catalog. Semantic embeddings and live provider quality were not evaluated.

Architecture: deterministic first, model only for ambiguity

Audio or text→Session and request controls→Actionability gate
Hybrid retrieval→Confident: DB projection|Ambiguous: authorized tools→Short grounded cue

Small talk and unsupported local facts take a silent shadow path. Silence is a valid reliability outcome.

Retrieval and grounding

The catalog layer combines weighted FTS5/BM25 retrieval with trigram and RapidFuzz recovery, then applies structured constraints for attributes such as amperage, voltage, size, length, and material. Optional embeddings exist, but the audited catalog contained 0 of 907 vectors, so the measured results describe lexical and structured retrieval only.

The model path cannot query arbitrary authoritative facts. It must call product search first. Price, location, and availability tools reject SKUs outside the most recent search results. After tool execution, the server projects current database facts and replaces ungrounded model-authored claims with deterministic clarification or silence.

Conversation state is bounded and explicit. Product referents and candidate families support follow-ups such as “how much is it?” without another model call. Topic changes clear stale focus; explicit session IDs isolate context, while omitted IDs remain stateless.

Offline evaluation

The repository’s offline check disables provider APIs and runs catalog, retrieval, grounding, referent, lifecycle, streaming, transcript, and frontend checks. The complete check passed at the audited commit.

These are small fixture results, not store-floor accuracy. The evaluator replaces provider resolution with a controlled fake. It measures retrieval and routing behavior, not real-model response quality.

Reliability and privacy controls

  • Provider failure stays silent and does not leak its error to the earpiece.
  • Fact tools reject unrelated valid SKUs when search did not authorize them.
  • Remote billable access is denied by default and requires a configured demo token.
  • Direct remote clients cannot spoof a localhost host header to bypass protection.
  • Sessionless requests are stateless; explicit sessions are isolated and bounded.
  • Turn IDs prevent stale generations from updating the client, and TTS fragments remain ordered.

Turn evidence includes path, intent, matches, referent, tool trace, and stage-level latency. JSONL logging redacts transcript, answer, model input/output, and tool traces unless content logging is explicitly enabled. Tests also verify owner-only log permissions.

These are implemented demo protections, not enterprise identity controls. The system does not integrate SSO, role-based store entitlements, secrets rotation, or centralized audit retention.

AI economics without invented dollars

The routing policy used the model path on 8 of 34 cases, bypassing it for approximately 76.5% of the synthetic workload. That is evidence of model-call avoidance, not a cost result. Token usage is not logged, and the offline evaluator uses a fake resolver, so cost per successful task cannot be calculated honestly.

What remains to prove

The next credible evaluation needs held-out, human-labeled store-floor requests; a populated and tested embedding path; noisy real audio; provider-level grounded-answer scoring; end-to-end STT/LLM/TTS latency and cost; and enterprise identity controls.

The strongest pattern already demonstrated is not “voice plus RAG.” It is the combination of fail-silent behavior, retrieval-authorized fact tools, post-model database projection, bounded memory, and selective model use.
